## このアプリ(Lainチャット)での用途別推奨

### 🏆 デフォルト(現状維持): qwen/qwen3.8-27b
日本語ロールプレイの質・指示追従(IFBench 79.5%)・速度(450tps)のバランスが最も良い。
玲音の寡黙な「間」の再現はCJK特化のqwenが有利。thinking none⇔default の切替も公式サポート。
弱点は出力料金($4/1M)だが、無料枠では問題にならない。

### 💰 精度・コスパ重視の乗り換え先: openai/gpt-oss-120b
MMLU 90%は本リスト最高精度で、料金はqwenの**1/5以下**。
しかも **Groq組込みのブラウザ検索・コード実行**が使える(このアプリの自作 wired_search と併用可)。
しりとり等の文字遊びは reasoning (low) を有効にするとqwenより安定する可能性。
日本語の繊細さはqwenに一歩譲る(MMMLU 81.3%)。Production枠なのでPreviewのqwenより提供が安定。

### ⚡ 速度・軽さ重視: openai/gpt-oss-20b
**1000tpsは体感で明らかに速い**(打字演出が追いつかないレベル)。最安。
ただし多言語スコアが一段落ちる(75.7%)ため、玲音の日本語が時々ぎこちなくなる trade-off。

### ❌ 非推奨
- **llama-3.1-8b-instant**: MMLU 69.4%・日本語の人格維持が最も苦手。しりとりもさらに悪化。レート制限が緩い場合の緊急避難用
- **llama-3.3-70b-versatile**: 280tpsと遅く、reasoning非対応(しりとり改善の見込みなし)、日本語RPはqwenに劣る。英語チャットなら良モデル

## 検証方法 (自分でA/Bテストする)

⚙ CONFIG → MODEL を切り替えて、同じセリフで比較するのが確実:

1. 日本語ロールプレイ: 「こんばんは。今日の気分は?」→ 玲音らしさ(寡黙さ・「……」の間)
2. しりとり: 「しりとりしよう。最初の言葉は『りんご』」→ 3往復して末文字が正しいか
3. 検索: 「今日のニュース教えて」→ ツール呼び出しの判断・出典提示
4. 速度: 送信からタイプライター開始までの体感時間

THINKING MODE は qwen/gpt-oss でのみ有効 (llama系には自動で送られません)。
